☁ Sync Google Drive

Pour synchroniser tes tableaux entre appareils, il faut un Client ID Google OAuth 2.0.

  1. Va sur console.cloud.google.com
  2. Crée un projet → Activer l'API Google Drive
  3. Identifiants → Créer des identifiants → ID client OAuth 2.0
    Type : Application Web
  4. Dans Origines JavaScript autorisées, ajoute :
    http://localhost:8080 (ou ton URL)
  5. Copie l'ID client ci-dessous
  6. Pour ouvrir le fichier depuis localhost :
    python -m http.server 8080
